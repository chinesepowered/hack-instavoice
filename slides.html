The technical bet

Boson has no pronunciation-scoring endpoint. Rather than fake phoneme scores, we score what actually marks a heritage speaker: stress and timing.

  • 1Synthesise the target in their cloned voice
  • 2RMS energy envelope of target + attempt
  • 3Align with DTW; walk the warping path back so every syllable knows where it landed
  • 4Words 45% · rhythm 35% · pace 20%

Architecture

BrowserAudioWorklet PCM16 @24k · envelopes + DTW run client-side, so the round trip carries ~200 floats, not audio
Direct WSSServer mints an ephemeral key; the browser speaks to Boson over its subprotocol. No audio proxy, no relay latency, key never ships
InstaCloudcompute --websocket + Postgres + S3 bucket, all ap-southeast

Found the hard way: timestamps is documented but returns null for every language — including Boson's own example. We derive syllable windows from the audio instead: Mandarin is syllable-timed, so N hanzi = N energy bursts.
